IAM STANDALONE - Investment Management Ledger
============================================

ONLY NEED: Node.js from https://nodejs.org/ (LTS version)

TO START:
  Double-click RUN-IAM.bat
  Keep the black window OPEN
  Open http://127.0.0.1:8000/health in browser - should show {"ok":true}

IF YOU DON'T HAVE THIS FOLDER YET:
  From the full Kalici repo, double-click GET-IAM-NOW.bat
  It downloads these files to Desktop\Kalici automatically.

DO NOT CLOSE the black window while using Investment Management.
